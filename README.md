# تطبيق بوابة طلاب كلية شمال كردفان الإلكترونية 🎓🇸🇩

تطبيق موبايل هجين وتفاعلي مخصص لطلاب **كلية شمال كردفان**، يتيح للطلاب الاستعلام السريع والآمن عن النتائج الأكاديمية الفردية، والجداول الدراسية الأسبوعية، وجداول الامتحانات النهائية.

---

## 📱 الميزات والوظائف الرئيسية:

### 1. استعلام الطالب بالبيانات الأكاديمية:
- إدخال **الرقم الجامعي** (رقم الجلوس / القيد الأكاديمي).
- اختيار **القسم الأكاديمي**:
  - علوم الحاسوب وتقنية المعلومات
  - علوم التمريض والمختبرات الطبية
  - العلوم الإدارية والاقتصاد
  - التربية والآداب
- اختيار **العام الدراسي** (السنة الأولى، الثانية، الثالثة، الرابعة).
- اختيار **الفصل الدراسي** (الفصل الأول / الفصل الثاني).

### 2. عرض النتيجة الفردية مع الخصوصية التامة:
- يتم رفع كشف نتائج الدفعة كاملاً بواسطة إدارة الكلية كملف **PDF**.
- يقوم النظام بالبحث الداخلي بالرقم الجامعي وعرض **نتيجة الطالب المستعلم فقط** (المقررات، الدرجات، التقدير الحرفي، والمعدل التراكمي GPA وحالة النجاح).
- **حماية الخصوصية:** حجب درجات وكشوفات باقي زملاء الدفعة عن الطالب.
- إمكانية طباعة إفادة النتيجة الرسمية أو مشاركتها عبر WhatsApp.

### 3. الجدول الدراسي الأسبوعي (Lecture Timetable):
- استعراض مواعيد المحاضرات موزعة على أيام الأسبوع.
- توضيح اسم المقرر، توقيت المحاضرة، اسم أستاذ المادة، والقاعة أو المعمل المخصص.

### 4. جدول الامتحانات النهائية (Exam Timetable):
- مواعيد وجداول امتحانات نهاية الفصل الدراسي.
- توضيح التاريخ، الوقت، مدة الامتحان، ورقم القاعة.
- بطاقة تنبيه ذكية للامتحان القادم.

### 5. بوابة إدارة الكلية والمسجل الأكاديمي:
- واجهة خاصة لإدارة الكلية لرفع ملفات PDF لكشوفات نتائج الدفعة بضغطة زر وتحديث قواعد البيانات.

## 🚀 كيفية تشغيل التطبيق وتجربته:
- افتح ملف `kordofan_student_app.html` مباشرة في أي متصفح على هاتفك أو حاسوبك.
- لتجربة وضع الهاتف على الحاسوب: اضغط `F12` ثم فعّل وضع الموبايل (`Ctrl + Shift + M`).

### 🧪 أرقام جامعية نموذجية للتجربة السريعة:
- **`1045`**: طالب علوم حاسوب - السنة الثالثة (الفصل الثاني).
- **`1046`**: طالبة علوم حاسوب - السنة الثالثة (الفصل الثاني).
- **`2012`**: طالب علوم صحية وتمريض - السنة الثانية (الفصل الثاني).
