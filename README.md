# تطبيق ولوحة تحكم عيادة الدكتورة نوال مكبي (نساء وتوليد) 🩺👶🤰

نظام رقمي وطبي متكامل يشمل **تطبيق موبايل للمريضات** و **لوحة تحكم إدارية وطبية متطورة للعيادة (Dashboard)**.

---

## 🖥️ 1. لوحة تحكم العيادة (`dashboard.html`):
- **إحصائيات حية (KPI Cards):**
  - إجمالي المواعيد المسجلة.
  - المواعيد التي بانتظار تأكيد الدكتورة.
  - المواعيد المؤكدة.
  - حالات متابعة الحمل والسونار.
- **إدارة المواعيد وتأكيدها:**
  - جدول تفاعلي بالاسم، الهاتف، نوع الكشف، التاريخ، والوقت.
  - زر **"تأكيد الحجز وإرسال واتساب للمريضة"** بنقرة واحدة برسالة رسمية مهيأة.
  - فلترة وتصفية (الكل / قيد الانتظار / مؤكد).
  - بحث فوري بالاسم أو رقم الهاتف.
- **إضافة موعد كشف يدوياً:**
  - لتسجيل الحجوزات الواردة هاتفياً أو من خلال الاستقبال في العيادة.
- **مزامنة فورية:** مشاركة البيانات تلقائياً بين تطبيق المريضات ولوحة التحكم.

---

## 📱 2. تطبيق الموبايل للمريضات (`index.html`):
1. **شاشة الدخول الترحيبية (Splash Screen):**
   - تصميم جمالي بصورة أم حامل عالية الدقة ووسم "رعاية أمومة متكاملة".
   - زر تفاعلي: **"دخول إلى العيادة"**.
2. **الشاشة الرئيسية (Home):**
   - بنر ترحيبي وتوعوي، زر حجز سريع، عرض الخدمات الطبية، ومواعيد العمل.
3. **نظام حجز المواعيد وإشعار الواتساب التلقائي:**
   - نموذج حجز سهل مع توجيه إشعار فوري لطلب الحجز إلى رقم واتساب العيادة.
4. **حاسبة الحمل وموعد الولادة المتوقع:**
   - تعتمد على قاعدة ناغلي لحساب تاريخ الولادة وأسبوع الحمل والثلث الحالي.
5. **شاشة الخدمات الطبية التخصصية:**
   - السونار الرباعي، متابعة الحمل عالي الخطورة، الولادة بدون ألم، وعلاج تأخر الإنجاب وتكيسات المبايض.

---

## 🚀 كيفية تشغيل المشروع وتجربته:
- **لتجربة لوحة التحكم:** افتح ملف `dashboard.html` في المتصفح.
- **لتجربة تطبيق الهاتف للمريضات:** افتح ملف `index.html` في المتصفح (ويمكن الضغط على `F12` لتفعيل وضع الهاتف المحمول).

# تطبيق بوابة طلاب كلية شمال كردفان الأكاديمية 🎓🇸🇩 (`kordofan_student_app.html`)

تطبيق موبايل هجين وتفاعلي مخصص لطلاب **كلية شمال كردفان**، للاستعلام الفوري عن النتائج الفردية، والجداول الدراسية الأسبوعية، وجداول الامتحانات النهائية.

### 🌟 الميزات المنفذة:
1. **استعلام الطالب بالرقم الجامعي والعام والفصل:**
   - إدخال الرقم الجامعي واختيار التخصص (علوم حاسوب، تمريض ومختبرات، اقتصاد، تربية) والعام والفصل الدراسي.
2. **عرض النتيجة الفردية مع خصوصية كاملة:**
   - يرفع المسجل الأكاديمي كشف نتائج الدفعة كاملاً بصيغة **PDF**.
   - النظام يستخرج ويعرض للطالب **درجاته ونتيجته ومعدله GPA فقط** دون إظهار درجات زملائه في الدفعة لحماية الخصوصية.
3. **الجدول الدراسي الأسبوعي (Lecture Timetable):**
   - استعراض مواعيد المحاضرات، أسماء الأساتذة والقاعات المخصصة لكل فرقة.
4. **جدول الامتحانات النهائية:**
   - مواعيد المواد، القاعات، مع مؤشر تنازلي للامتحان القادم.
5. **بوابة المسجل الأكاديمي (Admin Portal):**
   - تتيح لإدارة الكلية رفع كشوفات PDF للنتائج واعتمادها.
